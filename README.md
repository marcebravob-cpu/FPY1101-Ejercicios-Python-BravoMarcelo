# FPY1101-Ejercicios-Python-BravoMarcelo

Ejercicio 1: Sistema de solicitudes de mantenimiento de jardines urbanos.

Descripción: Una municipalidad recibe solicitudes para realizar labores de mantenimiento en jardines públicos. Desarrolle una aplicación de consola en Python para registrar solicitudes, consultar pendientes, buscar reportes, finalizar trabajos y obtener indicadores.
